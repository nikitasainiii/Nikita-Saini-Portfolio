A modern, high-performance portfolio website built with **TanStack Start**, **React 19**, and **Tailwind CSS 4**. This portfolio showcases the work, skills, and research of Nikita Saini — a Computer Science Engineer, Web Developer, and Data Analyst.

---

## ✨ Features

- 🏎️ **Lightning Fast**: Built on TanStack Start for optimized server-side rendering and hydration.
- 📱 **Fully Responsive**: Seamless experience across mobile, tablet, and desktop.
- 🎨 **Modern UI/UX**: Crafted with Shadcn/UI and custom animations for a premium feel.
- 📈 **Data-Driven**: Showcases projects, publications, and professional experience.
- ✉️ **Contact Form**: Integrated contact section for professional inquiries.
- 🌓 **Dark Mode Support**: Built-in support for high-contrast accessibility.

## 🛠️ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) (Full-stack React)
- **Library**: React 19
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Components**: [Shadcn/UI](https://ui.shadcn.com/) + Radix UI
- **Icons**: Lucide React
- **Type Safety**: TypeScript & Zod
- **Forms**: React Hook Form
- **Deployment**: Cloudflare Pages

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [Bun](https://bun.sh/) (Optional, but recommended)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nikitasainiii/Nikita-Saini-Portfolio.git
   cd Nikita-Saini-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   bun install
   # or
   npm install
   ```

3. **Start the development server:**
   ```bash
   bun dev
   # or
   npm run dev
   ```

4. **Build for production:**
   ```bash
   bun run build
   # or
   npm run build
   ```

## 🌐 Deployment

This project is optimized for **Cloudflare Pages**.

### Deploying via Wrangler CLI

1. **Login to Cloudflare:**
   ```bash
   npx wrangler login
   ```

2. **Deploy the project:**
   ```bash
   npx wrangler pages deploy .output/public
   ```

Alternatively, you can connect your GitHub repository to Cloudflare Pages for automatic CI/CD.
